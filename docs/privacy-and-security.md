# 数据隐私与安全方案

## 1. 数据分级和默认策略

| 类别 | 本项目例子 | 默认处理 |
|---|---|---|
| 虚构业务数据 | `DEMO-C-0001`、`demo-customer-0001@example.invalid` | 可用于演示；保留 `data_origin=SYNTHETIC` |
| 假名化外部数据 | Olist 匿名化商业记录、IEEE-CIS 匿名交易特征 | 非当前默认运行数据；按来源/批次隔离，遵守许可，不能称为纯虚构 |
| 敏感字段（不收集） | 真实姓名、手机、地址、证件号、完整支付标识 | 不导入、不记录；确有教学外需求时先评审必要性 |

仓库不含真实个人信息、支付凭据、数据集 CSV、密码或密钥。`.example` 文件只有占位符，不是可用凭据。`example.invalid` 是保留的无效域名，避免误指向真实用户。

## 2. 掩码与加密的区别

- 页面展示 `demo-****@example.invalid` 或 `DEMO-****-0001` 只是**展示掩码**，减少界面暴露，**不是加密**。
- 若接口仍返回完整值、数据库仍保存明文、日志出现原值，攻击者仍能读取；前端隐藏不能替代访问控制或加密。
- 首期契约默认只返回虚构主体标识及掩码邮箱，不返回电话、地址、证件号或支付凭据。
- 密码哈希适合密码校验，不适合需要还原的电话/地址；不能混淆哈希和可逆加密。

## 3. 确有必要时的应用层加密设计（未启用）

仅当后续确需敏感字段且完成需求评审后启用，首期不收集真实敏感信息：

1. Java 在写入前用 AES-256-GCM 加密；每条使用随机的 12 字节 nonce，且同一密钥不得复用 nonce。
2. 数据库分列保存 `ciphertext`、`nonce`、`key_version`、`aad_version`；AAD 可绑定租户/记录类型和稳定记录 ID。密文完整性校验失败不得返回明文。
3. 主密钥由仓库外的环境变量或正式密钥管理系统注入；推荐 KMS/密钥管理系统，密钥文件不入库、不进镜像、不进 Git。
4. `.env`、`.env.*`（除示例）、运行时密钥目录忽略提交；`.env.example` 使用 `replace-with...` 占位符。
5. 密钥轮换保留版本标识，先读旧版本、写新版本，再受控迁移；轮换计划、访问授权和撤销流程是启用前置条件。
6. 密文不适合普通等值索引；确需检索应单独评估专用盲索引及其泄露风险，首版不实现。
7. 加解密在受控服务边界执行，密文与密钥分开授权；前端不得持有主密钥。

## 4. 日志、接口和存储

- 不记录请求/响应正文、Authorization、Cookie、数据库密码、密钥、邮箱、电话、地址、支付信息、SQL 参数或模型特征明细。
- 业务日志只记录 `requestId`、路由模板、状态码、耗时；审计需要时仅记录虚构订单 ID、操作者 ID、结果。生产环境操作者身份须先认证。
- 全局异常响应不返回堆栈、SQL、内部主机或模型响应正文；详细服务端异常也须避免敏感上下文。
- MySQL 使用最小权限账号；不使用 root 作为应用账号；生产环境另行配置 TLS、备份、网络限制和认证授权。
- 前端不注入 HTML；以普通文本展示原因码。不能信任客户端传入的复核人或角色。
- **v2 演示认证**：BCrypt + 内存用户 + Session；登录 `changeSessionId()`；Cookie `HttpOnly`、`SameSite=Lax`、本地 `Secure=false`；写操作校验 CSRF；角色为 ANALYST/REVIEWER/ADMIN。复核身份取服务端 `Authentication`，忽略请求体 `reviewerId`。
- **审计**：只记录操作者、角色、动作、目标 ID、结果、`requestId` 和非敏感计数；不记录请求正文、密码、Cookie、邮箱、原始载荷。审计表追加式，但当前无防篡改/WORM 存储。
- 演示账号密码是虚构默认值，可由 `APP_DEMO_*_PASSWORD` 覆盖；不要用于真实系统。生产仍需外部 IdP、MFA、会话吊销、限流、TLS、密钥管理和集中审计。
- 当前骨架**没有**生产级登录/身份治理、限流、HTTPS、KMS、审计防篡改或依赖全量漏洞扫描，不能宣称已达到生产风控安全要求。

## 5. 外部数据隔离

Olist、IEEE-CIS、Handbook 和本项目虚构数据必须分开登记、分批导入并保留来源；不同数据集的 ID、订单和标签不得互连或冒充同一真实业务。外部数据许可、使用目的及再分发条件未满足前，相应接入标记阻塞。当前可运行路径不需要外部数据；v2 导入只在管理员显式触发时读取本地目录，缺失时返回受控错误，不自动下载。

IEEE-CIS 的 `is_fraud` 只进入 `eval_ieee_transaction`，不进入订单、告警或复核表；训练产物只保存匿名数值权重和特征名，不保存原始交易行。Olist 的原始载荷可能包含客户引用/城市等字段，导入只保留必要列，`raw_payload` 禁止放真实敏感信息。
