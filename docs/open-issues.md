# 未决事项与范围限制

状态更新：2026-11-07。v2 已实现演示认证、导入/质量/审计、IEEE 训练/评测和五页 UI；以下只列**仍未完成或仍有阻塞**的事项。已解决项也标注边界，避免把演示实现当成生产完成。

| 优先级 | 事项 | 当前状态/阻塞 | 验收条件 |
|---|---|---|---|
| P0 | IEEE-CIS 原始/行级数据公开再分发及商业使用 | **阻塞**：竞赛规则要求非商业、接收者接受规则；未获书面授权 | 每位使用者从官方接受规则；公开/商业场景取得授权；仓库不含 CSV/行级导出 |
| P0 | Handbook 预生成 PKL 许可 | **阻塞**：独立仓库未找到 LICENSE | 作者书面许可，或改用许可明确的独立方案 |
| P0 | 真实敏感字段 | 未启用；无 AES-GCM/KMS/轮换实现 | 必要性评审 + AES-GCM + 仓库外密钥 + 轮换/访问审计 + 日志检查 |
| P1 | MySQL V1/V2/V3 实际执行 | **阻塞**：本机 MySQL 运行但无可用演示账号；未猜密码 | 用户提供最小权限账号，执行 V1/V3/种子，验证约束、索引、JSON、UTC、导入、事务、健康 200 UP |
| P1 | 真实 Olist/IEEE 数据导入 | 未执行；端到端只用 2 行 Olist + 300 行合成 IEEE 烟测 | 用户自行放置合法文件，核对行数、拒绝原因、质量检查、时间切分边界 |
| P1 | JDK/Spring 长期维护 | JDK 8 + Spring Boot 2.7.18，公开维护已结束；未做 Java/Python 全依赖漏洞扫描 | JDK 17 + 受支持 Boot 3，重跑 33 项并做依赖审计 |
| P1 | 生产身份与安全 | 仅演示 Session/BCrypt/内存账号/CSRF；无 MFA、IdP、会话吊销、限流、TLS、审计防篡改 | 外部 IdP/MFA、短期会话、集中审计、TLS、限流、密钥管理、渗透测试 |
| P2 | 并发导入幂等竞态 | 逻辑为“查哈希→插入”，真实 MySQL 并发同文件可能触发唯一键冲突而非复用批次 | 捕获唯一键冲突并返回已有批次；并发测试 |
| P2 | Olist → DWS 特征 | 不伪造账户年龄/24h 频次，故 Olist 订单不自动可评分 | 明确可用代理特征/缺失策略并评审，不能把缺失值当 0 |
| P2 | 自动告警编排 | 评分只写历史，不自动生成告警 | 阈值策略、幂等、重复评分处理、超时补偿、队列与集成测试 |
| P2 | 模型有效性与公平性 | 合成夹具 PR-AUC=1.0 只证明管线可跑；未用真实 IEEE 数据评估，无校准/漂移/群体公平性 | 合法数据、时间外推、校准、漂移监控、复核偏差与公平性评估 |
| P2 | 生产部署/恢复 | 仅本机 HTTP；无 Docker/高可用/备份恢复实战/公网防护 | TLS、反向代理、备份恢复演练、监控告警、成本与安全评审；公网/付费需明确批准 |
| P3 | 前端可访问性 | 有语义标签、键盘可用与移动端断言，但未做完整 WCAG/屏幕阅读器审计 | 自动化 + 人工可访问性审查 |

## 已解决但仍有边界的项

| 事项 | 当前实现 | 边界 |
|---|---|---|
| 演示认证/RBAC/CSRF | Session + BCrypt + 三角色 + CSRF Cookie | 非生产 IAM；演示密码可覆盖但不强制改密 |
| ODS→DWD 导入 | Olist 订单/支付/客户可选，幂等批次 | 不做完整地址/商品/评价建模；时间按无时区解析 |
| 数据质量 | 行数、支付覆盖、金额、日期/标签、时间切分检查 | 检查规则有限，不等于数据真实性审计 |
| 模型训练/评测 | 纯标准库逻辑回归，70/15/15 时间切分，PR-AUC 等 | 单机演示；训练段 >20k 抽样；非生产模型平台 |
| 前端五页 | 登录/订单/告警/详情复核/质量/模型/健康 | 无完整订单管理、批量操作或可视化图表 |
| 审计 | 追加式事件表/内存列表 | 无 WORM、签名或集中日志 |

## 明确不声称具备

- 大规模分布式数仓、实时计算、高可用或弹性扩展。
- 完整业务流程、生产级安全或真实欺诈识别能力。
- 外部数据集的匿名下载验证、原始 CSV 逐列审计或数据真实性保证。
- 当前未实际执行的测试/数据库验证；以 [verification.md](verification.md) 为准。
